# Python Taschenrechner

Ein Konsolen-Taschenrechner mit grundlegenden und erweiterten mathematischen Funktionen, Statistik und einfachen Umrechnungen.

## Funktionen

### Mathematik
- Addition
- Subtraktion
- Multiplikation
- Division
- Potenzierung
- Modulo
- Quadratwurzel
- Sinus
- Kosinus
- Tangens
- Natürlicher Logarithmus
- Logarithmus mit beliebiger Basis
- Fakultät

### Statistik
- Mittelwert (Mean)
- Median
- Standardabweichung

### Umrechner
- Kilometer → Meter
- Meter → Zentimeter
- Kilogramm → Gramm
- Celsius → Fahrenheit

## Fehlerbehandlung

Das Programm überprüft Benutzereingaben und zeigt Fehlermeldungen bei ungültigen Zahlen, Division durch Null oder ungültigen mathematischen Operationen.

## Technologien

- Python
- `math`
- `statistics`

## Starten

Python muss auf dem Computer installiert sein.

Das Programm kann mit folgendem Befehl gestartet werden:

```bash
python calculator.py
```
## Projekt

Dieses Projekt wurde erstellt, um grundlegende Python-Kenntnisse zu üben und praktische Erfahrung mit Benutzereingaben, Bedingungen, Schleifen, Fehlerbehandlung und Standardbibliotheken zu sammeln.
